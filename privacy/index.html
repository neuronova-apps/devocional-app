Política de privacidad

Esta política describe el comportamiento real de la demo web actual: qué registros personales se guardan en el navegador, cómo se validan y migran, qué ejemplos no se persisten y qué funciones todavía no existen.

01

Responsable

Mi Momento forma parte de Neuronova Apps, iniciativa personal e independiente desarrollada por Gabriel Berrospi.

02

Alcance actual

Esta política corresponde a la demo web funcional publicada en GitHub Pages. Actualmente permite crear oraciones y reflexiones locales. La biblioteca devocional, la finalización de planes, las notas de seguimiento, las rachas y el progreso devocional todavía son funciones demostrativas o no implementadas.

Una futura aplicación móvil o una versión con cuentas, sincronización, analítica u otros servicios deberá revisar y actualizar esta política antes de habilitar esas funciones.

03

Datos y almacenamiento local

La demo puede utilizarse sin crear una cuenta y sin proporcionar nombre, correo electrónico, teléfono u otros datos identificativos.

Mi Momento utiliza localStorage con la clave mimomento-local-v1. El objeto guardado declara version: 1 y contiene dos colecciones: prayers para oraciones personales y journal para reflexiones personales.

En una oración pueden conservarse ID local, título, texto, categoría, fecha visible, estado activa/respondida y fecha técnica de creación. En una reflexión pueden conservarse ID local, fecha visible, texto y fecha técnica de creación.

Estos datos se procesan en el navegador y no se envían a una base de datos propia de Mi Momento en la configuración actual.

04

Validación, recuperación y migración

Antes de utilizar datos restaurados, la aplicación comprueba la versión del formato y valida cada registro. Los IDs inválidos o duplicados se descartan; los textos se normalizan y limitan; las categorías y estados desconocidos se sustituyen por valores seguros.

Si el JSON almacenado no puede leerse, la aplicación intenta recuperar registros personales válidos desde las claves heredadas devotionalPrayers y devotionalJournal. Si la migración se guarda correctamente, esas claves antiguas se eliminan.

Si se encuentra una versión futura que esta demo no entiende, no se sobrescribe ese formato. La aplicación continúa en memoria durante la sesión.

Si el navegador bloquea localStorage, la demo también puede seguir funcionando temporalmente en memoria; en ese caso los nuevos cambios no sobreviven a una recarga.

05

Datos de demostración

La interfaz incluye oraciones y reflexiones precargadas para mostrar el diseño. Esos ejemplos se mantienen en el código como contenido de muestra y ya no se serializan en localStorage.

La lista visible combina temporalmente los registros personales y los ejemplos, pero los contadores personales utilizan únicamente la información creada por la persona usuaria. Los ejemplos tampoco pueden modificarse como registros propios.

No se guardan actualmente como historial personal las rachas, porcentajes de progreso, días de actividad, finalización de devocionales, avance de planes, notas de seguimiento ni preferencias de perfil.

06

Uso de la información

Los registros locales se utilizan para volver a mostrar las oraciones y reflexiones personales, mantener el estado activa/respondida y calcular contadores locales de esos registros.

Mi Momento no utiliza actualmente esos textos para publicidad personalizada, elaboración de perfiles comerciales ni venta de datos.

07

Compartición de datos

Mi Momento no sincroniza actualmente las oraciones o reflexiones con un servidor propio y no incorpora una función para compartir esos registros con otras personas.

Si en el futuro se habilita sincronización, copia de seguridad, comunidad, analítica o publicidad, la política se actualizará antes de utilizar esos servicios.

08

Seguridad y límites del almacenamiento local

localStorage mantiene los datos dentro del perfil del navegador, pero no constituye por sí mismo cifrado de extremo a extremo ni una bóveda protegida por contraseña. Una persona con acceso al mismo dispositivo, perfil del navegador o herramientas de desarrollo podría acceder a los datos del sitio.

Por tratarse de textos potencialmente íntimos, se recomienda no utilizar la demo para información que requiera un nivel de protección superior al almacenamiento local del navegador.

09

Retención y eliminación

La demo actual todavía no ofrece controles de edición o eliminación individual para oraciones y entradas del diario. Los datos guardados permanecen en localStorage hasta que el navegador los elimine o la persona borre los datos del sitio desde la configuración del navegador.

No existe una cuenta de usuario ni una base de datos remota de Mi Momento que requiera una solicitud separada de eliminación.

10

Servicios de terceros

La versión web se publica mediante GitHub Pages y utiliza recursos compartidos del ecosistema Neuronova Apps. No utiliza actualmente servicios publicitarios ni un SDK propio de analítica para las funciones principales descritas en esta política.

Los enlaces externos se rigen por las políticas del servicio de destino.

11

Funciones futuras y publicación móvil

Antes de incorporar cuentas, sincronización, copias de seguridad, recordatorios remotos, analítica, publicidad, SDK externos o una versión móvil distribuida mediante una tienda, se revisarán el tratamiento de datos, permisos, bibliotecas y declaraciones públicas aplicables.

Las declaraciones de seguridad de datos de cualquier tienda deberán corresponder al funcionamiento real de la versión publicada, no a esta demo ni a funciones previstas.
